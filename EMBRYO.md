# Embryo Storage Cluster

Embryo Storage Cluster is Embryo-Zero's fork of [ceph](https://github.com/ceph/ceph) (cbd2314, commit cbd2314). It does distributed storage for data centers.

- Our changes live on the `embryo` branch. The original license files (COPYING, COPYING-GPL2, COPYING-LGPL2.1, COPYING-LGPL3) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
